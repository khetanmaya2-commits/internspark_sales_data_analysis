# Sales Performance Analysis Dashboard

## Overview

This project focuses on analyzing sales performance across different regions, product categories, and time periods using Python and Power BI. 
The objective was to identify business trends, top-performing products, seasonal patterns, and provide actionable business recommendations through data visualization and analytics.

---

## Objectives

* Clean and prepare sales/order data
* Analyze sales performance across regions and categories
* Identify top and bottom performing products
* Perform time-based and seasonal analysis
* Build an interactive Power BI dashboard
* Generate business insights and tactical recommendations

---

## Tools & Technologies Used

* Python
* Pandas
* Matplotlib
* Power BI
* Google Colab
* Git & GitHub

---

## Data Cleaning & Preparation

The dataset was cleaned and transformed using Python:

* Removed duplicate records
* Handled missing values
* Converted date columns into datetime format
* Extracted Month and Year from Order Date
* Standardized data types
* Prepared data for visualization and dashboarding

---

## Key KPIs

* Total Revenue
* Total Orders
* Average Order Value
* Regional Sales Performance

---

## Dashboard Features

* Monthly Sales Trend Analysis
* Regional Sales Performance
* Category-wise Sales Analysis
* Top 10 Products by Sales
* Interactive Slicers & Filters
* Reset Filters Button
* Modern Gradient UI Design

---

## Key Insights

* Certain regions generated significantly higher sales compared to others.
* Seasonal trends revealed peak sales periods during specific months.
* Top-selling products contributed a major portion of total revenue.
* Some products consistently underperformed and may require strategic improvement.

---

## Business Recommendations

1. Increase marketing efforts in low-performing regions.
2. Promote top-selling products using targeted campaigns.
3. Improve inventory planning during peak demand periods.
4. Bundle low-performing products with best sellers.
5. Use seasonal trends to optimize promotional strategies.
